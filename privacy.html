Privacy policy

Last updated: 20.11.2026

Bastion is a personal app used only by its developer. It has no other users and no server.

Google data

  • With the user's permission, Bastion reads and edits the user's own Google Calendar events, only to show them in the app and to create or change events the user asks for.
  • Calendar data is stored only on the user's own devices. It is never sold, shared with third parties, or used for advertising.
  • Sign-in credentials are kept in the operating system's secure storage on the user's device.
  • Access can be removed at any time in the app, or at myaccount.google.com/permissions.

Bastion's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
